# Bối cảnh Manga Reader

Ứng dụng cá nhân ngoại tuyến Windows. [Đặc tả đầy đủ](REQUIREMENTS.md) là nguồn yêu cầu; tài liệu này phản ánh mã đã có.

Giai đoạn 1–5: đã có đường dẫn tuyệt đối, settings UTF-8 ghi atomic, GUI Tkinter tiếng Việt, chọn/ghi nhớ thư mục, hai nút chính và trạng thái/thống kê. ScanController chạy một daemon worker, queue/after xử lý kết quả trên main thread; chỉ mở trình duyệt sau scan_and_publish thành công, hỗ trợ lỗi/thử lại. Đóng cửa sổ hủy timer. Scanner, website thư viện và reader đã tích hợp; build/shortcut chưa triển khai.

Luồng hiện có: Manager → worker scanner → atomic library.js → browser index.html (website sẽ có ở giai đoạn 4). Scanner schema_version=1, source{name,uri}, scanned_at UTC, stats{stories,chapters,images}, stories[{id,name,cover,chapter_count,chapters:[{id,name,images,image_count}]}]. ID SHA-256 rút gọn từ đường dẫn tương đối. Natural sorting NFKC/casefold/số nguyên với tie-break xác định. Bỏ qua truyện/tập không ảnh. Lỗi đọc hoặc file biến mất hủy toàn scan, không ghi library cũ. Không hỗ trợ symlink/junction; báo lỗi thay vì đi theo liên kết.

File URI từ Path.as_uri (Unicode/#/%/&/khác ổ đĩa). Windows IO dùng prefix mở rộng hỗ trợ đường dẫn dài, URI không có prefix nội bộ. Đọc header ảnh xác nhận quyền và lấy kích thước tốt nhất có thể, không giải mã/đổi ảnh. `image_meta.py` nhận diện PNG/GIF/JPEG/WebP/AVIF, giới hạn header tối đa 256KiB; kích thước chưa biết là null. Tập có thêm image_sizes song song images. Ghi JSON escaped, allow_nan=false → temp cùng folder → fsync → os.replace.

Website hiện có: index.html nạp config/library/app/reader bằng script thường, không fetch. Grid dark mode responsive, 20 truyện/trang; tìm live NFD bỏ dấu/đ=d/gom khoảng trắng; clamp và reset trang; detail theo thứ tự scanner, ảnh cover lỗi/empty; hash library/story/read, F5/Back/Forward. Tên nhập DOM qua textContent. Root giữ file cấu hình/README; app/web/tests/scripts/docs tách chức năng. Tài nguyên không cần Internet.

Kiểm chứng giai đoạn 5: `python -m unittest discover -v` đạt 36/36 test, 0 lỗi/skip; diff check đạt. Gồm 22 Python/Tk/scanner/header và 14 browser Chromium thật file://: ảnh C→D/Unicode, thư viện/tìm/phân trang/hash/F5/Back/Forward/mobile, reader/4 controls/F/width/shortcuts/progress/recent10, file mất/tập mất/storage bị chặn, ảnh trễ 350ms, resize và đổi width giữ ảnh/tỷ lệ. Đã xem screenshot reader desktop. Sửa đồng bộ test theo route và aria-busy, tránh nhận nhầm DOM tập cũ. Chạy source `python -m app.manager` hoặc scripts/start.bat. Build/Search chưa có script. Giới hạn: browser khác và đường dẫn dài browser chưa kiểm. Git: mỗi giai đoạn test đạt cập nhật hai tài liệu rồi commit; không push/commit dữ liệu cá nhân/build.

## Reader, tiến độ và cấu hình thực tế

`reader.js` hiển thị ảnh dọc bằng wrapper aspect-ratio, ảnh object-fit contain, gap theo config mặc định 0; kích thước header giữ chỗ cho lazy loading, ảnh lỗi giữ chỗ và thông báo. Kích thước header không biết được cập nhật khi load, giữ anchor đang xem; khôi phục chỉ probe ảnh trước target chưa có size, concurrency 4, timeout mỗi ảnh 8 giây. Không đảm bảo mọi ảnh hỏng/metadata xoay đều giữ tỷ lệ header chính xác trước khi browser giải mã.

Bốn vùng cố định: trên tên/trở về/F; dưới cuộn/Home/End/width/Esc/tiến độ; trái/phải tập trước/sau disable tại biên. Desktop có lề tránh che ảnh; mobile nút bên xuống gần thanh dưới. F ẩn toàn bộ `.reader-control` cả thông báo và vùng cuối, padding về 0; giữ anchor trang/tỷ lệ, không fullscreen và không hiện theo chuột. F5/mở reader mới luôn có UI để tránh mắc kẹt. Cuối tập có nút tiếp theo, không tự chuyển.

Phím: Space ±80% viewport (Shift để lên), ←/→ tập, Home/End đầu/cuối, F ẩn/hiện, +/-100px (400..1600), Esc danh sách tập. Bỏ qua input/textarea/select/contenteditable, Ctrl/Alt/Meta; xử lý Equal/NumpadAdd/Subtract. F5 do browser.

Storage được probe và try/catch, lỗi đọc dữ liệu fallback; lỗi ghi vẫn đọc bình thường, thông báo UI. Key `manga-reader.progress.v1`: map story ID → {chapterId,time,chapters:{chapterId:{page,ratio,imageName,time}}}; page zero-based, ratio 0..1, imageName là tên URI để tìm lại trang khi ảnh phía trước bị xóa. `manga-reader.width.v1` lưu chiều rộng. Lưu debounce scroll 180ms, khi rời route/pagehide/ẩn tab. Đọc tiếp dùng tập gần nhất còn tồn tại hoặc tập đầu; trang mất clamp index. Recent lấy 10 truyện duy nhất theo time. Không đồng bộ giữa trình duyệt/máy; file:// storage phụ thuộc browser. `?start=1` reset vị trí một lần, sau đó replaceState chỉ hash để F5 resume; không phụ thuộc server fallback.

Mọi config có hiệu lực: STORIES_PER_PAGE grid; READER_IMAGE_WIDTH/MIN/MAX/STEP width; IMAGE_GAP khoảng ảnh; SPACE_SCROLL_RATIO/SMOOTH_SCROLL cuộn; LIVE_SEARCH input hay change; SEARCH_IGNORE_ACCENTS normalization; LAZY_LOAD_IMAGES loading; SAVE_READING_POSITION progress/recent; DARK_MODE màu; RECENT_STORIES_LIMIT lịch sử. Width user hợp lệ override default. Chỉnh `web/js/config.js` khi chạy source; thông tin frozen config sẽ cập nhật giai đoạn 6.
